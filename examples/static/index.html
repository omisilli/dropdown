A head that opens a body.

Plain HTML with four attributes. The package places and shows the body; everything you see here — colours, the arrow, the shadow — is this page's own CSS.

Choosing closes it

Buttons inside the body work like links: pick one and it closes.

Placing

Above the head without flipping
Centred under the head
Lined up with the head's right edge

data-pg-dropdown-y and -x work without flipping too: the body stays inside its container and goes exactly where it is told. Without flip it does not watch the screen — near an edge it can run off, so use flip there.

Flip

Room on the right: opens rightwards Upwards near the bottom A popover in the top layer
No room on the right: opens leftwards Upwards near the bottom A popover in the top layer

data-pg-dropdown-flip moves the body when there is no room. Scroll until this row sits near the bottom of the screen and open them again: they open upwards.

Per axis

Opens upwards comes down only without room above
Centred under its head Upwards near the bottom Never flipped sideways
Always above never flipped but still on screen

Each axis is its own choice: -flip="y" only moves up or down, -flip="x" only sideways, -flip="none" never — the body still floats above everything and stays on screen.

Screen edge

Pushed back on screen, and kept 12px from the edge on a phone, 24px from 48rem

This page sets --pg-dropdown-edge: 12px on :root and 24px from 48rem up — mobile first, like any CSS. Flipped bodies never come closer to the screen's edges than that.

No names match.

Put an <input data-pg-dropdown-search> in the body and mark the options data-pg-dropdown-item. By default case and accents are ignored: sahin finds Şahin, olstad finds Ølstad, ilk is finds İlknur Işık. Aa makes case count. The third keeps accents, and each name carries its own lang: Turkish names follow Turkish rules, so irmak does not find Irmak there (in Turkish, I lowers to ı).

Scroll threshold

Scroll the page a little: it stays open until you pass 40px

data-pg-dropdown-scroll-threshold="40" — without it, any scroll you start closes the dropdown.

Things to try

  • Open one, then the other — only one stays open.
  • Scroll the language list: the page stays put and the list stays open.
  • Scroll the page, press outside, or hit Esc — it closes.
  • Open the language list in the bar: it escapes the blurred bar and stays on screen at the right edge.
  • Tab to a head, open it with Enter, tab through the links — tabbing past the last one closes it.
